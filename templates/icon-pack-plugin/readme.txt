Icon collections for Easy SVG Support Pro.

== Description ==

Every folder under `icons/` is one collection. Pro reads each folder, cleans
every SVG on the way in and offers the icons in the block editor, the Icon
block, Elementor, WPBakery, ACF, Meta Box and `easy_svg_icon()`.

The icons keep their own licences. See `manifest.json` in each folder.

== Frequently Asked Questions ==

= Does this do anything without Easy SVG Support Pro? =

No. Without Pro the icons stay hidden, and the plugin says so in the admin.

= The icons do not show up. =

Under Icons, Features switch on "Theme & folder sources". For WordPress's Icon
block switch on "Multiple collections" as well.
